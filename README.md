# simulador-epidemia-escolar_ACC2026
Simulador d’epidèmies en entorn escolar basat en autòmats cel·lulars desenvolupat amb HTML, CSS i JavaScript.

Aquest projecte consisteix en un simulador interactiu de la propagació d’una epidèmia dins d’un entorn escolar. El model utilitza autòmats cel·lulars per representar la dinàmica de contagi entre individus i permet observar com es desenvolupa una epidèmia en funció de diferents paràmetres.

El simulador ha estat desenvolupat amb HTML, CSS i JavaScript, i està pensat com una eina visual per entendre millor els mecanismes de transmissió de malalties infeccioses en poblacions estructurades.

L’objectiu principal del projecte és analitzar i visualitzar com es propaga una malaltia infecciosa en un entorn escolar, així com estudiar com factors com la infectivitat, el contacte entre individus i les mesures de seguretat influeixen en l’evolució del contagi.
